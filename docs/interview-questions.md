# 面接・商談で使える質問リスト（下書き）

参画・入社の前に、現場の様子を確かめるための質問。

何を確かめたいかが見える質問（「残業はありますか？」など）は、模範的な答えが返ってきやすい。そこで、大きく聞く質問を軸にして、**答えに何が出てこなかったか**を見る。気になる答えが返ってきたら、掘り下げ用の質問で確かめる。

## 軸にする質問

1. **開発を推進する上で一番大切にしていることは何ですか？**
   - 気をつける答え：お客さんや納期の話だけで、チームやメンバーの話が出てこない
   - 関連する項目：人への関心
2. **最近いちばん大変だった時期と、それをどう乗り越えたかを教えてください。**
   - 気をつける答え：「みんなで遅くまで頑張った」で終わる。範囲や期限を見直した話が出てこない
   - 関連する項目：残業文化、変更管理
3. **チームがうまくいっていると感じるのは、どんなときですか？**
   - 気をつける答え：数字や成果の話だけで、メンバーの様子や働きやすさに触れない
   - 関連する項目：人への関心、扱いの公正さ
4. **どんな人に来てほしいですか？**
   - 気をつける答え：「スピード感」「何でもやってくれる人」など、負担を引き受ける人を求める言葉ばかり
   - 関連する項目：残業文化、時間への配慮

## 掘り下げ用の質問

軸の質問で気になる答えが返ってきたときに使う。

### 残業文化

- リリースなど、期限が決まっている作業の直前は、チームはどんな様子ですか？直近の例があれば教えてください。
- スケジュールが遅れそうなとき、どのように調整されていますか？

### 変更管理

- 当初の計画や仕様が変わったとき、具体的にどのように進めましたか？最近の例があれば教えてください。
- 初日の時点で、アカウントや開発環境はどこまで用意されていますか？

### 扱いの公正さ

- メンバーの進捗や成果は、どのように見ていますか？
- 立場に関係なく、提案や懸念を出せる場はありますか？実際に取り入れられた例はありますか？

### 時間への配慮

- 打ち合わせは週にどのくらいありますか？
- チームの普段のやり取りは、主に何を使っていますか？

### 心理的安全性

- 直近の障害やミスのあと、チームではどのような振り返りをしましたか？
- 最近入った方は、わからないことがあったとき、どこで誰に聞いていましたか？

### 人への関心

- メンバーの負荷や働きやすさについて話す場はありますか？話した結果、何か変わった例はありますか？
- 最近、チームで認められた工夫や取り組みには、どのようなものがありますか？
